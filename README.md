# 红纸鸢 · 纸扎冥婚

一款中式恐怖文字推理游戏。

民国二十三年，浙东槐阴村。一场办了九十年的冥婚即将续上最后一程，而你被请来做新郎。

游戏采用多视角叙事、状态感知、时辰推进、随机事件和隐藏成就，让同一个故事在不同选择与不同视角下呈现不同真相。

## 开始游戏

项目不需要安装依赖或构建。

### 方式一：使用 Node.js 静态服务器

```bash
node server.js
```

然后在浏览器打开：

```text
http://localhost:8080
```

### 方式二：直接打开页面

也可以直接打开 `index.html`，但使用本地服务器更适合测试音频、存档和浏览器行为。

## 游戏内容

### 新郎视角

玩家需要在槐阴村陈家老宅中调查三处地点：

- 西厢书房：查阅族谱，寻找桃木簪和婚书线索
- 东厢新房：调查纸扎新娘、镜台和婚书残页
- 后院祠堂：寻找真正的禁忌册和阿鸢留下的证据
- 地宫：拼合完整真相，决定最终如何离开槐阴村

游戏中的规则真假混杂。玩家需要结合石碑、假禁忌册、真禁忌册和场景线索判断哪些行为会带来后果。

### 四条真禁忌

真禁忌册揭示的核心规则包括：

- 不系红绳
- 不亲手揭新娘盖头
- 不饮合卺酒
- 子时三刻听见唢呐时不回首

违反规则会影响理智、阴气和可达成的结局。

### 状态感知

- 理智降低时，正文会出现异常文字、词语变形和幻象选项
- 阴气升高时，界面和关键文字会出现更强的异变效果
- 理智过低时会出现心跳音效和纸鸢飘落效果
- 时辰从戌时推进到寅时，影响剧情节奏和最终抉择

### 多周目内容

- 新郎视角包含 6 个主要结局
- 完成特定结局后解锁阿鸢视角和喜婆视角
- 通关后再次开始新郎视角，可以继承部分记忆
- 结局录和成就页会使用浏览器本地存储保存进度

## 测试

### 回归测试

```bash
node tests/regression.js
```

覆盖内容包括：

- 进房未取关键证据时是否可以折返，避免真相线软锁
- 时辰是否始终单调推进
- 子时前进入地宫并解锁 `fast_truth`
- 四条真禁忌是否可以全部违反后存活
- 守礼成就是否只在正确视角和结局条件下解锁
- 全道具、纸鸢收集和多视角解锁
- 幻象点击次数是否能跨存档保留
- 随机事件池是否包含全部道具事件且不生成矛盾事件
- 新郎、阿鸢、喜婆三种视角的随机播放冒烟检查

### 变异测试

```bash
node tests/mutation-check.js
```

变异测试会：

1. 先运行回归测试，确认基线为绿色
2. 逐个临时还原已经修复的缺陷
3. 再次运行回归测试，确认对应断言变红
4. 无论测试结果如何，从临时快照恢复源码

该脚本会临时改写以下游戏源码文件，因此运行前应确保工作区没有未保存的重要改动，且不要与其他编辑或测试进程并行运行：

- `js/core.js`
- `js/scenes.js`
- `js/systems.js`
- `js/scenes_ayuan.js`
- `js/scenes_po.js`

当前变异测试包含软锁、时辰回拨、不可达成就、错误视角成就、死道具、存档计数、随机事件和三视角死胡同等检查。

## 存档与数据

游戏使用浏览器 `localStorage` 保存：

- 当前游戏存档
- 已解锁结局
- 已完成成就
- 已解锁视角
- New Game+ 记忆状态

清除浏览器站点数据会同时清空这些内容。

## 技术特点

- 原生 HTML、CSS 和 JavaScript
- 无第三方运行时依赖
- 无构建工具
- Web Audio API 生成交互音效与氛围音
- 本地 Node.js 服务器只负责静态文件分发
- 游戏状态通过场景函数和显式状态标记推进
